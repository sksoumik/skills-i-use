Redesign the entire application from scratch with a polished, modern, premium quality UI/UX that looks production ready and App Store worthy.

   • Make the app feel native to iOS and iPadOS

   • Use clean layouts with strong visual hierarchy
   • Use spacing intentionally, avoid clutter
   • Every screen should feel carefully crafted and balanced

   • Improve padding, margins, alignment, corner radius consistency, shadows, and responsiveness
   • Use premium looking color combinations with proper contrast

3. User Experience
   • Improve overall UX flow and interaction quality
   • Reduce cognitive overload
   • Make important actions obvious
   • Ensure smooth navigation and intuitive layout structure
   • Add thoughtful micro interactions and transitions where appropriate
   • Improve accessibility and readability

5. Engineering Expectations
   • Use clean scalable architecture
   • Ensure reusable UI components
   • Maintain design consistency across all screens
   • Use modern SwiftUI best practices
   • Ensure responsive layouts for all supported iPhone and iPad sizes
   • Use smooth animations with restraint
   • Avoid overdesigned flashy UI

6. Output Expectations
   For every screen:
   • Explain the design reasoning briefly
   • Show improved layout structure
   • Improve UX decisions
   • Improve component hierarchy
   • Improve visual consistency

The final result should look like a high budget startup app built by an elite Silicon Valley product team, not a beginner project.

Think deeply before redesigning. Make deliberate design decisions instead of generic AI generated layouts.
