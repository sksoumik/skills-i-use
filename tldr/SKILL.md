---
name: tldr
description: Shrink your previous answer to a TL;DR and key takeaways in simple English.
disable-model-invocation: true
---

Write a TL;DR of your previous response. If I give an argument (for example "the last 3 answers" or pasted text), write the TL;DR of that instead.

1. Find the point: the one thing I most need to know from the response. Usually it is the direct answer, the result, or the decision it asks of me.
2. Pick the takeaways: the 2 to 4 facts I would lose if I skipped the response. Keep a number only when it carries the result. Keep a file path or command only when I must use it.
3. Write it in this shape, and nothing else:

   **TL;DR:** one sentence, about 15 words.

   - takeaway, one line, about 12 words
   - takeaway

   **You need to:** the one decision or step left for me. Leave this line out when nothing waits on me.

Write in ASD-STE100 Simplified Technical English: everyday words, one idea per sentence, no dashes inside a sentence. Every fact comes from the source response; use only what it says.

Done when the whole TL;DR is under 80 words, and every takeaway points to something the source response says.
